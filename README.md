# 📝 OMTodo – React Todo List App

A modern and responsive **Todo List application** built using **React + Vite**.  
It helps users manage daily tasks efficiently with features like **add, edit, delete, mark complete**, and **dark mode**.  
All tasks are stored in **localStorage**, so data persists even after refreshing the page.

---

## 🚀 Live Demo

🔗 **Demo Link:** https://omtodo.vercel.app/

---

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks with confirmation
- ✅ Mark tasks as completed
- 👁️ Show / hide completed tasks
- 🌙 Dark mode & ☀️ Light mode toggle
- 💾 Persistent storage using **localStorage**
- 📱 Responsive UI (mobile & desktop friendly)

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **State Management:** React Hooks (`useState`, `useEffect`, `useRef`)
- **Unique IDs:** UUID
- **Deployment:** Vercel
